Read these steps in order — install the mod first, then the Windows app.

The desktop app does not run inside FS25. It only reads data.json, which the in-game mod creates while you play (or while a dedicated server runs with the mod). Until you load a save with the mod enabled, the dashboard shows “waiting for data” even after the installer finishes.

App 4.2.1 · Mod 3.4.0.7 · Dashboard at http://localhost:8766 after setup

Updating from 4.2 / 3.4.0.6: close Farm Dashboard and Farming Simulator → download the new Setup and FS25_FarmDashboard.zip → replace the app and the mod zip in Documents\My Games\FarmingSimulator2025\mods\ (delete any old unpacked folder) → load the save → start the app. Dedicated: replace the mod on the host, restart the server, then update joined clients.

Dedicated servers: prefer join as client (same mod on a joined PC → local data.json → app Local mode — no FTP). FTP remains available for headless-only hosts. Giants port 8080 is an optional XML feed, not a substitute for data.json.

Stage A — Install the mod

  1. Download FS25_FarmDashboard.zip from this page (recommended) or GitHub Releases.
  2. Copy the zip into your FS25 mods folder:
    Documents\My Games\FarmingSimulator2025\mods\
    Alternative: extract to mods\FS25_FarmDashboard\ with modDesc.xml at the folder root.
  3. Start Farming Simulator 25 once so the game registers the mod.

Stage B — Enable on every save

Repeat for each savegame (and each dedicated-server save) that should use the dashboard:

  1. Open the save’s Mods list in FS25.
  2. Enable Farm Dashboard / FS25 Farm Dashboard.
  3. Load the save and enter the world — the main menu alone is not enough.

Stage C — Confirm data.json is updating

After about one minute in-game, check this path on your PC:

Documents\My Games\FarmingSimulator2025\modSettings\FS25_FarmDashboard\<savegame>\data.json

The file should exist and its Modified time should advance while you play. For dedicated join as client, confirm this path on the joined client PC (not only on the server). For FTP, confirm the file on the server profile you will poll.

Stage D — Install the Windows app

  1. Download and run FS25-Farm-Dashboard-Setup-4.2.1.exe from this page (recommended) or GitHub Releases.
  2. Choose your language on the welcome page and complete the installer.
  3. Launch Farm Dashboard from the Start menu.

Stage E — First launch & Server Manager

On first launch the app opens Server Manager if no servers are configured yet.

Setup walk-through

  1. Pick your language (top-right on Setup).
  2. Click Auto-detect saves for local PC play (or for a dedicated join-as-client mirror already writing on this PC), or add a row manually.
  3. For dedicated hosts: prefer Local after join-as-client (see below). For headless-only / GPortal-style FTP: add Dedicated Server (FTP) with host, credentials, profile path, and save slot.
  4. Optional: Scan FS25 mods for dashboard images (vehicle icons from your mod folder).
  5. With at least one server in the list, click Launch Dashboard → open http://localhost:8766.

Dedicated server — join as client (no FTP)

Recommended when someone can stay connected to the dedicated server. The same mod automatically mirrors data.json from the dedicated authority to every joined client; the desktop app watches that local folder. Works for the legacy app (4.2.1 line) and v5.

  1. Install FS25_FarmDashboard.zip on the dedicated server (Stages A–B on that save).
  2. On the PC that runs Farm Dashboard, install the same updated mod and join the server as a client (spare/alt account or admin playing).
  3. Mirroring starts automatically when you join — no in-game opt-in switch.
  4. Confirm local Documents\My Games\FarmingSimulator2025\modSettings\FS25_FarmDashboard\mirror_<slot>\data.json updates while the client stays connected.
  5. In Setup or Settings → Servers & saves, add a Local server (or Auto-detect) pointing at that folder — no FTP.

Limits: needs at least one connected client; empty server (zero players) does not mirror until someone joins; large exports may lag a few seconds; requires the updated mod with export mirror on server and client.

Dedicated server — FTP (Advanced)

  1. Complete Stages A–C on the server — mod enabled, save loaded, data.json present on the server profile.
  2. In Setup or Settings → Servers & saves, add FTP host, port, username, password, base profile path, and save slot folder.
  3. Optional HTTP feed (Giants dedicated XML on port 8080) improves vehicle age, prices, and market history when available — it does not replace data.json.
  4. Set Poll every (1–25 minutes). Local saves (including join-as-client) use file watching; FTP uses this schedule.

Post-install checks

Landing page
Section cards with counts (or zeros until data arrives).
Data-source badge
XML + Live + API (or a subset if unavailable).
Settings → Servers
Correct local path (SP or join-as-client) or FTP host + save slot.
Wrong save empty
Repeat Stage B for that save.

Troubleshooting

Waiting for data

Complete Stages B and C. Verify the save path in Settings → Servers. The mod must be enabled and you must have entered the world at least once.

Port 8766 in use

Close other apps using port 8766, then restart Farm Dashboard.

Join-as-client: no local data.json

Keep the client connected. Confirm the same updated mod on server and client. An empty dedicated server with zero players does not mirror until someone joins — use FTP for headless-only.

FTP never updates

Check FTP credentials, save slot folder name, and firewall. Set poll interval to at least 1 minute. Confirm data.json exists on the server profile. Prefer join-as-client when someone can stay connected.

Blank or broken after upgrade

Update both the app (4.2.1) and mod (3.4.0.7) from the same release line.
