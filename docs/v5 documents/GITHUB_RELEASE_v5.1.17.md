# Farm Dashboard V5 5.1.17

**Windows app 5.1.17 · in-game mod 5.1.0.9 · Farming Simulator 25**

Farm Dashboard puts your save's fields, vehicles, animals, productions, storage and economy on a second screen. The base dashboard needs only its own game mod. Pages for other supported mods appear when those mods are loaded in the selected save.

## What is in this release

- The V5 interface is the default app experience, including save selection, dedicated multiplayer linking, companion pages and a fleet map.
- The packaged section photographs and splash logo load again. Their filename case now matches the images inside the installed app.
- The Windows installer registers Farm Dashboard V5 in Installed apps with a usable uninstaller. Keep data retains your dashboard profile; Full removal clears that profile. Your FS25 saves are outside the app's removal scope.
- The matching 5.1.0.9 mod carries the tested game-export and multiplayer-stream changes. The installer and mod ZIP are separate files; install both from this release.

## Install

1. Close Farming Simulator 25 before replacing the mod. Keep exactly one file called `FS25_FarmDashboard.zip` in your FS25 `mods` folder, and enable it for the save. Dedicated servers and joining clients need the same canonical ZIP.
2. Run `FS25-Farm-Dashboard-V5-Setup-5.1.17.exe` and open **Farm Dashboard V5**.
3. Choose your local save, link the server you joined in-game, or configure FTP for an unattended dedicated source. Wait for a completed export; a held snapshot is the last known farm picture, not a live update.

See the [installation guide](https://github.com/WizardlyPayload/FarmHub/blob/main/docs/v5%20documents/INSTALL.md), [user manual](https://github.com/WizardlyPayload/FarmHub/blob/main/docs/v5%20documents/USER_MANUAL.md) and [optional-mod guide](https://github.com/WizardlyPayload/FarmHub/blob/main/docs/v5%20documents/COMPANION_MODS.md).

The installer is unsigned, so Windows may display a publisher or SmartScreen warning. The app is free. Do not disable Windows security protections to install it.
