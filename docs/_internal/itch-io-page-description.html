FS25 Farm Dashboard V5

Your fields, fleet, pastures, storage, economy, productions, and fleet map — on screens that update while you play. A lightweight in-game mod exports live data; a Windows desktop app shows it on a second monitor or LAN tablet.

App 5.3 · Mod 5.2 · 27 languages · local saves, dedicated join as client (no FTP), or FTP (Advanced)

Fixed in 5.3: When a local save slot is reused for a different map, the dashboard identifies the newly selected save and waits for its own fresh export instead of showing stale data from the previous map.

Added in 5.2.7: Orchards for grapes, olives, coffee and bananas; limited read-only Highlands Fishing, Pumps N' Hoses and Emergency Pack cards when those packs are loaded; clearer DLC production names and volumes; Catuaí and Kinlaig map images; and improved Windows upgrade registration. New local saves need one in-game save, then Auto-Detect Local Saves in the dashboard's Settings.

Classic V4 is still here. If you like the old six home cards, keep Farm Dashboard V4. V5 is a separate install. Auto-update on V4 will not replace it with V5. Use the matching mod from your chosen app release; V4 compatibility was not retested with this V5 mod.

How it works

  1. The mod writes live farm data to data.json (SP, MP host, or dedicated).
  2. On a dedicated host you can join as a client — the authority mirrors the export so the app uses Local mode (no FTP). FTP remains for headless-only admins.
  3. The Windows app merges the Lua export with savegame XML when available.
  4. V5 listens at http://localhost:8768. Classic V4 stays on 8766 if you keep it installed.

Quick start

  1. Download the V5 mod package (expected itch wrapper farm-dashobaord-fs25-mod-v5.zip) and FS25-Farm-Dashboard-V5-Setup-5.3.0.exe from this page. Check the displayed versions: mod 5.2.0.0 and app 5.3.0.
  2. Open the downloaded mod package and copy its inner FS25_FarmDashboard.zip into Documents\My Games\FarmingSimulator2025\mods\. Keep the inner ZIP intact. Enable it for the save and load the world so data.json is created. For a newly created local save, save in-game once and then use Auto-Detect Local Saves in Settings.
  3. Run the V5 Setup. Start Menu: Farm Dashboard V5.
  4. Prefer the classic cards? Download the separate V4 Setup instead (or keep the one you already have).

Works alongside

The base dashboard needs only its own game mod. Selected optional mods add bounded readings when loaded for the chosen save; a mod's presence alone does not promise every feature or combination. Production Control and Distribution Redux are not claimed compatible with the reviewed normal StockGuard build. See the supported-mod readings and install guide for their limits.
