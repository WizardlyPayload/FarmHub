⬡ FS25 Farm Management Dashboard

Your fields, fleet, livestock, economy, and productions — in one dashboard that updates while you play. A lightweight in-game mod exports live data; a Windows desktop app serves the UI in your browser at localhost:8766.

App 4.2.1 · Mod 3.4.0.7 · 27 languages · local saves, dedicated join as client (no FTP), or FTP (Advanced)

Hotfix for Farming Simulator 1.21: after the game’s 1.21 update, the mod could fill the game log with repeated copyFile errors while saving a map overview image. 4.2.1 / 3.4.0.7 uses the correct yes/no flag and stops retrying forever. This is noisy logs / a map-overview hiccup — not a broken game. How to update: close the app and FS25 → download the new Setup + FS25_FarmDashboard.zip → replace the app and the mod in Documents\My Games\FarmingSimulator2025\mods\ → load the save → start the app. Dedicated hosts: replace the mod on the server, restart, then update clients.

How it works

  1. The mod writes live farm data to data.json from your save (SP, MP host, or dedicated).
  2. On a dedicated host you can join as a client with the same mod — the authority mirrors the export to that PC’s local data.json so the app uses Local mode (no FTP). FTP remains for headless-only admins.
  3. The Windows app merges the Lua export with savegame XML when available — a real dashboard, not a static page.
  4. Open http://localhost:8766 on a second monitor, tablet (LAN), or phone on your Wi‑Fi.

Quick start

  1. Download FS25_FarmDashboard.zip and FS25-Farm-Dashboard-Setup-4.2.1.exe from itch.io (recommended) or GitHub Releases → enable the mod on your save.
  2. Load the save once in-game so the mod creates data.json.
  3. Install and run FS25-Farm-Dashboard-Setup-4.2.1.exe from the same download page.
  4. Open the dashboard; point Settings → Servers at your save path. Dedicated: prefer join-as-client + Local, or FTP if headless — see Installation instructions below.
