## How to install

1. Leave **Farm Dashboard V4** installed if you already have it.
2. Close Farming Simulator (and the dedicated server if you host).
3. Put **`FS25_FarmDashboard.zip`** in `Documents\My Games\FarmingSimulator2025\mods\` (replace the old zip or unpacked folder).
4. Run **`FS25-Farm-Dashboard-V5-Setup-5.0.3.exe`**. Start Menu: **Farm Dashboard V5**.
5. Load a save with the mod enabled, then launch V5 and complete Setup.

**URL:** `http://localhost:8768` (V4 stays on **8766**).

Installer is unsigned — Windows SmartScreen may warn. Guides: https://www.farmdashboard.co.uk/install.html

## What is new vs classic screens

- Sidebar: Save overview, Fields, Vehicles, Pastures, Productions, Storage, Economy, Fleet map
- Animals live under **Pastures**
- Field **Order** menu; GPS-only field merge
- **Storage** is its own screen (silos, moisture, bales)
- Fleet map with **layer** dropdown (crops, growth, soil, and more when exported)
- Optional companion panels (ADS, Red Tape, Fertilizer Depot, …) **only** when those mods are on the save
