⬡ FS25 Farm Dashboard V5

Your fields, fleet, pastures, storage, economy, productions, and fleet map — on new screens that update while you play. A lightweight in-game mod exports live data; a Windows desktop app shows it on a second monitor or LAN tablet.

App 5.2.7 · Mod 5.1.0.12 · 27 languages · local saves, dedicated join as client (no FTP), or FTP (Advanced)

New in 5.2.7: Orchards for grapes, olives, coffee and bananas; limited read-only Highlands Fishing, Pumps N' Hoses and Emergency Pack cards when those packs are loaded; clearer DLC production names and volumes; Catuaí and Kinlaig map images; and improved Windows upgrade registration. New local saves need one in-game save, then Auto-Detect Local Saves in the dashboard's Settings.

Classic V4 is still here. If you like the old six home cards, keep Farm Dashboard V4 (4.2.1). V5 is a separate install. Auto-update on V4 will not replace it with V5 — you only get the new screens if you download the V5 Setup. Use the matching mod from your chosen app release; V4 compatibility was not retested with this V5 mod.

Current 5.2.7 screens

The four screenshots in this page's gallery show the current Catuaí Save overview, Orchards, Productions, and Fleet map at full-screen resolution. See the GitHub README and V5 manual for more screen examples and detailed instructions.

  • Fields: crop stage, Order menu, GPS groups, soil bars, and next-step rules.

  • Pastures: sheds, food duration, birth warnings, and animal detail.

  • Fleet map: live pins on the PDA overview, with crop, growth, ownership, soil, and optional Precision Farming / Soil Fertilizer layers.

How it works

  1. The mod writes live farm data to data.json (SP, MP host, or dedicated).
  2. On a dedicated host you can join as a client — the authority mirrors the export so the app uses Local mode (no FTP). FTP remains for headless-only admins.
  3. The Windows app merges the Lua export with savegame XML when available.
  4. V5 listens at http://localhost:8768. Classic V4 stays on 8766 if you keep it installed.

Quick start

  1. Download FS25_FarmDashboard.zip and FS25-Farm-Dashboard-V5-Setup-5.2.7.exe from this page (filenames include V5).
  2. Enable the mod, load the save in-world once so data.json is created.
  3. Run the V5 Setup. Start Menu: Farm Dashboard V5.
  4. Prefer the classic cards? Download the V4 Setup instead (or keep the one you already have). You do not have to switch.

Full steps are in the Installation instructions section below this description.
