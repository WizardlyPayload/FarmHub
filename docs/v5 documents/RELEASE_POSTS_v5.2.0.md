## Own Farm Dashboard Discord announcement

**Farm Dashboard V5 5.2.0 is out.** The Windows app is 5.2.0 and the in-game mod is 5.1.0.9.

This is the new V5 dashboard for Farming Simulator 25: live save overview, fields and next-step rules, vehicles, pastures, productions, storage, economy and fleet map. It works with just the Farm Dashboard mod; optional companion panels appear only for mods you actually load. Dedicated-server players can use join-as-client or Advanced FTP.

Install both files from the same release: `FS25-Farm-Dashboard-V5-Setup-5.2.0.exe` and the single canonical `FS25_FarmDashboard.zip`. Replace the old mod ZIP rather than keeping a second copy. Close FS25 before replacing the mod, then enable it for the save and load into the world. The first empty startup export is not live farm data.

Download: https://wizardlypayload.itch.io/farm-dashobaord-fs25

Step-by-step guide: https://www.farmdashboard.co.uk/install.html

Prefer the classic dashboard? V4 4.2.1 stays separate on GitHub; V5 will not replace it through V4 auto-update. If anything looks wrong, tell us your app and mod versions, save type and what the dashboard says about freshness, with a screenshot or log excerpt. Please do not post passwords or server credentials.

The app is free/pay-what-you-want. The installer is unsigned, so Windows may show a publisher warning; please do not disable Windows security to use it.
