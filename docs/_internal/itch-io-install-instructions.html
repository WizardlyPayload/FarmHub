Troubleshooting

Waiting for data

Complete Stages B and C. The mod must be enabled and you must have entered the world at least once.

Wrong port

V5 uses 8768. V4 uses 8766. Do not mix them up. Both can run at once.

Did V4 auto-update to V5?

No. V4 auto-update stays on classic 4.2.1. V5 is a separate Setup.exe. You only get V5 if you install it yourself (or later choose a V5 in-app update on the V5 app).
