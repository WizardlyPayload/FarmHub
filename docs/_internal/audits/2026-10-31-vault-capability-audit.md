# FS25 vault capability audit

Status: **in progress**, 31 October 2026. This audit reopens the question that the 65-entry companion validation matrix could not answer: whether every vault mod with useful, distinct data has an honest Farm Dashboard reading. The completed matrix is evidence for its tested integrations, not a vault-wide pass.

- A title/category/source-file keyword pass put **118 ZIPs across 91 normalized titles** into an initial review queue. The queue includes duplicate versions, RF packages, native-data overlap and false positives; **118 is not a missing-integration count**. The sortable 1,201-row Lua triage file is `Z:\Graham\agent-comms\farmhub-companion-acceptance\VAULT-LUA-TRIAGE-2026-10-31.csv`. Every row is still a source-review lead, not an acceptance result. Lower-scoring rows must also be assessed before claiming the vault audit exhaustive.

## Decision rule

For each candidate, establish the exact current ZIP hash/version and source-owned state; decide whether that state is distinct from the normal game export, farm-scoped and safely readable; add a bounded collector and visible reading where justified; then compare a fresh nonempty game state, committed export and installed page. Classify native-game overlap and detection-only mods honestly. Never call an empty, unavailable or settings-only result a gameplay pass. RF-owned Ally work has priority; no direct Graham-PC UI use, public release, main push or RF/VPS changes are in scope.

Native-overlap examples need a different decision: the current `Statistics Extended` source reads `farm.stats.statistics` session and total counters, and `Animal Storage Overview` reads standard husbandry storage/food values to extend the in-game Animals frame. Those can motivate better generic Farm Dashboard views, but their source does not yet establish unique mod-owned state requiring an optional collector. `Ingame Time Operating Hours` changes the game's effective hour/fuel behaviour; avoid counting a second copy of native hours as a new mod-specific metric.

Other source triage remains open: `Invoices - Production Sales` and `Invoice VAT Account` declare a real `FS25_Invoices` dependency and hold invoice/receipt or VAT state; `Custom Used Market` maintains offer-generation settings while its offers may already be visible through native shop data. Their exact ownership, versions and useful display contract must be settled before promising an adapter. Dependency packages must be tested together, without silently requiring unrelated mods.
