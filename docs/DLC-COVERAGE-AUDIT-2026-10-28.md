Precision Farming is an internal mod in the local base-game extract, not a fourteenth `.dlc` archive. Season passes are purchase bundles, not extra installed packs to count here.

Evidence types used below:

- **Generic path** means current FarmHub code can enumerate a standard game object or save record if the DLC exposes it through that interface. It is a source-level capability, not a pack-specific acceptance result.
- **Dedicated path** means current FarmHub code explicitly reads the named DLC mechanic. It still needs a fresh installed-build game test.
- **Unverified** means either the pack's proprietary archive has no local unpacked source in this audit, the game object shape was not verified, or the end-to-end reading has not been observed.
- **Gap** means useful player information described by GIANTS or local DLC source is not explicitly exported/displayed by the inspected FarmHub path. A gap is a candidate, not a mandate to duplicate the game's own controls.
