Built for second-monitor farming

How it works

  • 1 The mod writes live farm data to data.json from your save (SP, MP host, or dedicated).
  • 2 The Windows app merges Lua export with savegame XML when available — a real dashboard, not a static page.
  • 3 Open http://localhost:8766 on a second monitor, tablet (LAN), or phone on your Wi‑Fi.
  • 4 Optional FTP mode for GPortal / Nitrado-style hosts — no game running on the dashboard PC.

Quick start

  1. Download FS25_FarmDashboard.zip → put in your FS25 mods folder → enable on your save.
  2. Load the save once in-game so the mod creates data.json.
  3. Install and run FS25-Farm-Dashboard-Setup-4.2.0.exe.
  4. Open the dashboard; point Settings → Servers at your save path or FTP if needed.
